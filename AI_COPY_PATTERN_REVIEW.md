# AI copy pattern review

Internal review only. Subjective style findings are documented here; automated tests cover only high-risk phrases and structural/factual errors.

| Phrase or pattern | Former location | Why it sounded generic or risky | Replacement approach | Changed |
| --- | --- | --- | --- | --- |
| `Professionelle Wiener Buchhaltung` / `Profesionalno knjigovodstvo` | DE/HR hero | Adjective-led positioning without proof | State service, audience and Vienna location | Yes |
| `breites Spektrum` / `širok raspon` | DE/HR services intro | Template-like breadth claim | Explain that service pages define possible scope | Yes |
| `Individuelle Lösungen` / `Individualna rješenja` | DE/HR services intro | Empty personalization claim | State that scope depends on records and situation | Yes |
| `klare, umsetzbare Einblicke` and `fundierte Entscheidungen` | German value block | Abstract outcome language repeated across accounting sites | Describe missing receipts, deadlines and unavailable figures | Yes |
| `jasne i primjenjive uvide` / `utemeljene odluke` | Croatian value block | Literal calque of the German marketing sentence | Describe documents, deadlines and required service | Yes |
| `Spezialisierung auf ausgewählte Branchen` | German homepage | Unsupported specialization | Replace with typical service situations and conditional capacity | Yes |
| `Poznavanje odabranih djelatnosti` | Croatian homepage | Same unsupported proof in translation | Same conditional situation-based section | Yes |
| `Seit 1997 begleitet …` / `od 1997. prati …` | About sections | Register date was converted into an experience/history claim | Keep exact register date only in the legal disclosure | Yes |
| `verlässliche Compliance` | German about | Outcome promise and English business jargon | Explain separate scoping and document responsibilities | Yes |
| `pouzdano ispunjavanje obveza` | Croatian about | Implied compliance outcome | Explain scope and source-document dependency | Yes |
| `Bereit für den nächsten Schritt?` / `Spremni za sljedeći korak?` | Final CTA | Generic funnel language | Name the discussion: support required | Yes |
| repeated `Nächster Schritt` / `Sljedeći korak` labels | Service CTAs | Repetitive funnel phrasing | Use `Anfrage` / `Upit` and service-specific CTA headings | Yes |
| `sauber`, `klar`, `strukturiert` in multiple H1s | German service pages | Repeated abstract adjectives | Use the specific task, records or service boundary | Yes |
| repeated three-step `verstehen – einordnen – begleiten` | German services | Formulaic cadence | Use service-specific actions and dependencies | Partly; shared structure retained for usability |
| repeated Croatian verbal-noun headings | Croatian services | German syntax carried into Croatian | Prefer direct nouns and concrete actions | Yes |
| `von … bis …` constructions | Homepage and service summaries | Common breadth shortcut without scope | List only described services | Yes |
| excessive em dashes | Positioning drafts | Can create polished but impersonal tone | Use full sentences and one factual qualifier | Yes |
| `Mehr erfahren` / `Saznajte više` alone | Homepage service links | Destination is unclear when scanning links | Append the exact service name | Yes |

## Deliberately retained patterns

- Repeated appointment-confirmation wording is intentional because it prevents a misleading booking impression.
- The service pages retain a consistent information order for accessibility and comparison, but their copy and requirements are service-specific.
- Vienna remains in route titles and principal search headings, but was removed from repetitive body sentences.
